# 运营商配置（MBN）

入口：设备详情 → 设备配置 → 运营商配置（MBN）。PC/SC 读卡器没有模组 MBN，不提供此入口。

MBN 会影响模组的驻网、漫游、数据及原生 IMS 能力。它不是自动/手动 PLMN 选网，也不是软件 WiFi calling 的 P-CSCF 配置。不根据运营商品牌猜配置，不因 VOXI 短信 488、Port-S 断开或软件 IMS 重连启动试配。

## 查询和应用

“读取模组”只发送查询，显示模组返回的原始名称、版本、日期以及 selected/activated；无法确定内置或导入来源的记录显示“来源未知”。ERROR、CME ERROR、超时与解析失败会明确显示，不把它们当成空列表。

选择配置或 AutoSel 后，单独点击“应用并重启模组”。任务保存原配置，通过模组重启恢复流程等待同一物理模组与同一张 SIM，再读回确认。仅收到 OK 不算成功。关闭网页不会停止任务，刷新可继续查看记录。

当前适配遵循 Quectel EC2x 的 QMBNCFG 语义：Select/AutoSel 在重启后核验，不无条件发送 Activate。实际能力来自该固件的 QMBNCFG 测试响应；未声明的写入能力不提供。不同系列和固件仍需真机验证。

MBN 操作不会解除飞行模式或运营商射频锁。需要 CFUN=1,1 的任务在写入前检查此限制；请在原有模式界面明确选择允许驻网的模式，而不是让 MBN 任务替你打开射频。

## 文件库、导入与删除

- 上传保存原始二进制、SHA-256、大小和来源声明；这不等于导入模组或验证文件兼容性。没有通用、可靠的公开 MBN 容器格式校验，不能凭扩展名认证其来源。
- 同名不同内容不覆盖。导入前需明确确认兼容性风险。QFUPL 从 CONNECT 到终态独占 AT 队列，核验上传长度和 XOR 校验和，再执行 Add 并读回新增的真实配置名。
- 文件不会因导入成功而自动激活。RAM 临时文件清理失败单独显示；导入未出现新配置会报错，不能推测成功。
- 下载的是 HiDeck 保留的原文件。**没有实现或假装支持模组内置 MBN 二进制导出**；配置快照不是二进制备份。
- 删除模组配置需要输入完整名称、确认无备份风险；selected/activated 的配置先应用不同替代项。被策略引用的配置要先修改策略。删除后重启读回确认。
- 文件库删除与模组删除是两个操作；策略或运行中操作仍引用的文件不能删除。已结束任务保留原文件的标识记录，删除文件库原件不会删除模组里的配置，也不会生成新的二进制备份。

## 策略和试配

可设置模组默认策略，以及按规范化 ICCID 保存的 SIM 策略：继承、模组 AutoSel、固定配置。固定配置同时约束型号、固件和已知版本；缺失配置明确失败，只有绑定时明确授权的文件才允许自动导入。

手工应用或试配成功的选择先保留在当前会话。要跨重启托管，使用“保存 MBN 策略”或“将当前已生效配置绑定本 SIM”。临时选择不自动跟随换卡；未绑定不会自动新增永久 SIM 策略。托管配置不由原有 VoLTE 初始化/恢复覆盖。

试配仅人工启动：选择并排序候选，每个候选最多一次，默认模组恢复 180 秒、驻网等待 120 秒、连续稳定观察 30 秒，可按任务修改。首次达到目标即结束，不表示该配置全局最佳。

目标可选：稳定驻网；经此模组数据接口访问指定 HTTP(S) URL（需流量授权）；原生 IMS 注册（需现有 VoLTE 模式和明确授权）。未采集真实通话/短信样本时始终标为未验证，本功能不自动拨号或发送短信。

取消请求等待当前命令安全结束。试配失败/取消时只对原模组、原 SIM 恢复原配置；换卡、拔出或控制通道失效不继续遍历候选。服务在任务中退出时标记“需要处理”，不盲目重放写入；先读取实际状态，再明确恢复。

同一物理模组、同一张 SIM 留有未确认任务时，重启或重新添加设备也不会自动重发 MBN 策略。先读取当前配置，再手动应用、恢复或完成试配并核验成功，才允许后续自动写入；历史任务记录不会删除。另一张 SIM 或另一台模组不继承此状态。上传文件或修改绑定设置不会解除未确认状态。

## 数据和部署

SQLite 使用 `mbn_assets`、`mbn_policies`、`mbn_operations` 保存文件信息、策略和任务；升级会为操作记录补充 `recovery_of` 恢复关联字段，保留原有记录。原文件位于工作目录的 `data/mbn/`。升级、迁移、回退前停止服务，整体备份数据库及 `data/mbn/`，仅备份其中之一不足以恢复完整文件库。

| 安装方式 | 文件目录 |
|---|---|
| Docker Compose | 已挂载的 `./data/mbn` → `/app/data/mbn` |
| OpenWrt 包 | `/var/lib/hideck/data/mbn`，必须把工作目录放在容量足够的持久存储上 |
| 飞牛 FPK | `${TRIM_PKGVAR}/data/mbn` → `/app/data/mbn` |

使用已有串口库，不新增厂商 GUI、ADB 或上传工具依赖。需要该设备实际可访问的 AT 端口。Docker/OpenWrt/飞牛原有 data 持久化和设备访问配置沿用。
