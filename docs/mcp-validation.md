# MCP 验证说明

本文说明已验证的范围和仍需在实际部署环境验收的场景。软件测试及协议连接成功不能替代真实短信、eSIM 和双向通话验收。

## 已验证范围

| 范围 | 验证内容 |
| --- | --- |
| MCP 协议 | 官方 SDK 客户端连接 Streamable HTTP，发现 125 项工具、录音资源模板，实际调用工具、接收进度并读取资源 |
| 输出契约与调用说明 | 全部工具的输出 Schema 可解析，初始化返回调用说明；实际查询、联系人写入及失败结果符合契约；输出不符合契约时明确报错且不重复执行 |
| 鉴权 | 拒绝无效、撤销和删除后的令牌；网页会话与 MCP 令牌不能混用；开关及跨源检查生效 |
| 令牌管理 | 创建时单次返回明文，数据库只保存摘要及元数据；撤销、删除后失效，其他令牌不受影响 |
| 接入诊断 | 仅接受网页会话；区分服务就绪、鉴权请求和实际调用；显示真实调用元数据，撤销及删除后清除记录，不包含令牌明文或业务参数 |
| 业务与并发 | 联系人写入、查询、导入、导出和删除；短信离线、SIM 变更、额度及发送失败处理；REST/MCP 共用 eSIM 操作锁；撤销和音频绑定的并发清理 |
| 网页音频授权 | 令牌隔离、媒体所有者验证、媒体重建、断开及撤销清理的服务级测试和前端回归，不代表真实双向音频已验收 |
| 长操作与资源 | 进度通知、取消传递及真实错误传播；录音鉴权读取和路径保护；文件内容输入，不接受宿主机路径 |
| 网页 | 前端测试、类型检查、受影响文件 ESLint 和生产构建；桌面及移动布局、令牌表单、客户端配置和接入诊断检查 |
| 后端 | 相关模块单元测试、race、vet 和构建；测试进程使用 60 秒硬超时，编译与测试按需分开执行 |

## 实际部署检查

1. 在网页开启 MCP 并创建测试令牌，使用 Agent 实际可访问的 HTTP 或 HTTPS 地址连接。
2. 确认工具发现成功，先执行只读查询；在「检查接入」中核对真实请求和调用记录。
3. 检查无令牌、撤销或删除后被拒绝，以及网页会话与 MCP 令牌不能混用。
4. HTTPS 保持证书校验；使用私有 CA 时配置客户端信任。反向代理部署同时检查 Host/Origin 转发。
5. 完成后删除测试令牌，确认记录及音频授权已清除。

## 尚未完成的真机验收

以下场景尚未完成统一真机验收，需要在具备相应模组、SIM、通话对端或 eSIM 资料的环境中验证。

| 场景 | 需要验证的结果 |
| --- | --- |
| 设备与网络 | 刷新、重启、网络配置、飞行模式、选网、AT/USSD 的实际状态和失败原因 |
| SIM、MBN 与运营商 | SIM 变更、MBN/eSIM 忙、运营商策略，以及 REST/MCP 同时操作的结果 |
| 短信 | 实际发送、投递、额度达到上限后的拒绝，以及中断后没有重复发送 |
| 网页音频 | 授权、多网页连接选择、媒体重建、关闭网页及撤销后失效 |
| 电话 | 拨出、来电接听、拒接、双向音频、DTMF、保持/恢复/切换、挂断及录音收尾 |
| 自动接听 | 音频转换、真实接听播放与录音；自动外呼录音模式单独验证 |
| eSIM 长操作 | 下载进度、真实失败、取消及超时后的芯片状态；切卡后身份恢复；中断后没有重复执行或虚假成功 |

接入方式及长操作的取消边界见 [MCP 接入文档](mcp.md)。
