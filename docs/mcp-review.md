# MCP 能力与限制

HiDeck 提供 125 个 MCP 工具，覆盖设备、网络、SIM/MBN、eSIM、短信、联系人、电话、代理、命令、余额、自动任务和诊断。具体工具及接入方式见 [接入文档](mcp.md)。

## 接入与结果

- 网页提供 Codex、Claude Code、Cursor、Gemini CLI、Hermes、DeepSeek dsh、Pi 和 Grok Build 的配置模板及「复制给 Agent」说明。
- 全部工具声明输出 Schema，初始化说明及关键工具描述包含标识符、分页、异步任务和失败处理方式。部分业务响应的 `data` 仍为通用结构，以对应工具 Schema 为准。
- 网页「检查接入」展示服务就绪状态、工具与契约数量，以及各令牌最近的鉴权请求和工具调用。记录仅保留在当前服务进程内，重启、撤销或删除后清除。
- 发送短信、外呼、切换 SIM 等写操作不会自动重试；请求中断后应先查询实际状态。

## 当前限制

| 范围 | 说明 |
| --- | --- |
| 呼叫设置 | 呼叫转移、主叫号码隐藏、呼入和呼出限制尚未开放 MCP 工具 |
| 新短信与来电 | 当前需要 Agent 主动查询，尚未提供 MCP 事件订阅 |
| 网页实时音频 | 需在电话页授权并保持网页音频连接有效，工具调用时指定 `audio_connection_id` |
| 异步任务 | 接受请求、排队和进度更新均不表示操作完成，需按返回 ID 查询最终状态 |
| 接入诊断 | 服务就绪不代表客户端网络或 TLS 已连通，也不代表设备已驻网 |
| 客户端与硬件验证 | 配置模板支持不等于全部原生客户端与硬件场景均已验收，详见 [验证说明](mcp-validation.md) |

系统升级、卸载、网页登录凭据和通知密钥配置不通过 MCP 开放。当前不提供 OAuth、按设备划分的令牌权限或 AI 实时语音模型。
