# WebDAV 归档与本地清理

入口：系统设置 → WebDAV 归档。

HiDeck 可以把短信、通话记录和通话录音增量写入 WebDAV。归档不改变短信收发、电话或通知流程；远端不可用时会明确记录失败，本地数据不会被当作已归档。

## 配置

填写 WebDAV 地址、用户名、密码和远端目录后先使用“测试连接”。测试会在远端目录写入并删除一个临时文件，因此账号必须具有建目录、写入和删除权限。
WebDAV 地址应填写最终地址；为避免 PUT 跳转被误判为成功，归档请求不会自动跟随 HTTP 重定向。

密码不会由设置读取接口返回。页面显示“已保存”时，密码输入框留空会保留现有密码；需要删除凭据时勾选“清除已保存的密码”。配置也可写入 [`config/config.example.yaml`](../config/config.example.yaml) 所示的 `archive` 段。

- `interval_hours`：定时归档周期，1～720 小时。
- `retention_days`：本地保留天数，1～3650 天。
- `auto_cleanup`：归档成功后自动清理，默认关闭。
- `include_sms`、`include_calls`、`include_recordings`：至少启用一项。

## 远端目录

在 `base_path` 下按类型和月份保存：

```text
hideck/
├── sms/2026/10/sms-123.json
├── call/2026/10/call-456.json
└── recording/2026/10/call_wwan0_20261016_120000.mp3
```

短信和通话记录使用 JSON；录音保留原文件。短信归档保留 ICCID 和 IMSI，换卡后仍可区分来源。每个对象的内容哈希和远端路径记录在本地归档台账中：内容未变时跳过上传，内容变化时覆盖对应对象。

## 清理规则

清理必须先预览，再明确确认。预览会生成与本次数据范围绑定的令牌；确认前数据发生变化时会拒绝清理并要求重新预览。HiDeck 只把同时满足以下条件的数据列入预览：

1. 已超过本地保留期；
2. 当前内容哈希与最后一次成功归档一致；
3. 含录音的通话记录，其录音也已成功归档；
4. 对应内容类型已在设置中启用。

上传失败、录音缺失、内容在归档后发生变化或没有归档台账时不会删除。自动清理也只在本轮归档完整成功后运行。清理短信后会重新计算短信联系人摘要和未读数量。

WebDAV 只负责备份，不等同于端到端加密。需要通过公网访问时应使用受信任的 HTTPS WebDAV，并限制账号只能访问专用目录。
